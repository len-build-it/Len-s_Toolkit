Len's Toolkit bundles and adapts 7 skills from [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), created by Next Level Builder.
The bundled source snapshot is commit `09170eec67eefd46a7ae85de61b40c194020f997` from 2026-09-27.

The skills are licensed under the MIT License.
Each independently installable skill folder under `templates/skills/` includes the upstream `LICENSE` and a `THIRD-PARTY-NOTICE.md` with attribution.
The source skill instructions, CSV data catalogs, and search scripts are retained, with punctuation normalized and script references adapted for local skill installations.
Heavy binary font assets (`canvas-fonts/*.ttf`) and build coverage artifacts are omitted to keep the distribution lightweight and text-focused.
